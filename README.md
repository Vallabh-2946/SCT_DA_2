# Data Cleaning and Preparation

## Objective

Clean and prepare the Global Superstore dataset using Python and Pandas.

## Tasks Performed

* Loaded dataset using Pandas
* Identified missing values
* Analyzed data quality issues
* Removed the Postal Code column due to excessive missing values
* Checked for duplicate records
* Converted date columns to proper datetime format
* Exported the cleaned dataset as CSV

## Tools Used

* Python
* Pandas
* Jupyter Notebook
* Git & GitHub

## Dataset

Global Superstore Dataset

## Outcome

Successfully cleaned and prepared the dataset for further analysis and visualization.
